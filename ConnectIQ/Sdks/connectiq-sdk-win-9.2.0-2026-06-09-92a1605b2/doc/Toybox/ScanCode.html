Instance Method Details

createQrCodeImage(value as ScanCode.QrCodeValue, ecc as ScanCode.QrCodeEcc, imageSize as Lang.Number, options as ScanCode.QrCodeOptions or Null) as Graphics.BufferedBitmap

Create a Quick Response Code image

Parameters:

  • value — (Lang.String, Lang.ByteArray, Lang.Array) —

    The value(s) to encode in the QR code image

  • ecc — (ScanCode.QrCodeEcc) —

    The error correction level

  • imageSize — (Lang.Number) —

    The width and height of the resulting QR code image in pixels.

  • options — (Lang.Dictionary) —

    Dictionary of options.

    • :minVersion — (Lang.Number) —

      The minimum QR code version. Default is 1.

    • :maxVersion — (Lang.Number) —

      The maximum QR code version. Default is 40.

    • :maskValue — (ScanCode.QrCodeMask) —

      The mask value. Default is QR_CODE_MASK_AUTO.

    • :color — (Graphics.ColorType) —

      The foreground color. Default is COLOR_BLACK.

    • :backgroundColor — (Graphics.ColorType) —

      The background color. Default is COLOR_WHITE.
